# Third-party components

BoardScope uses the following open-source components; retain their licenses when distributing binaries:

- [DirectShowLib.Standard](https://www.nuget.org/packages/DirectShowLib.Standard): DirectShow.NET, LGPL.
- [OpenCvSharp](https://github.com/shimat/opencvsharp): Apache 2.0, with native OpenCV and its third-party components.
- [NetVips](https://github.com/kleisauke/net-vips): MIT; native [libvips](https://github.com/libvips/libvips) is LGPL 2.1 or later with additional dependencies.
- [OpenSeadragon](https://github.com/openseadragon/openseadragon): BSD 3-Clause; its license is bundled at `src/BoardScope/wwwroot/vendor/LICENSE.txt`.
- .NET / ASP.NET Core / System.IO.Ports: Microsoft .NET components, MIT and applicable native runtime notices.
