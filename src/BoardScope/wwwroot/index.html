Orientation & automatic motion
Jog X+ goes right and Y+ goes up. Scan columns go right and rows go down, so automatic row moves use the opposite direction to jog Y+. Axis signs and X/Y swap apply to both.
Every row captures left to right. Auto scan returns this distance before column 1, then approaches forward to take up slack. Set above the mechanical play; 0 disables the approach move. Extra travel is included in the travel limits.

Frame size & angle calibration
Aim at a detailed, flat area and keep magnification fixed. The app uses phase correlation to measure a 0.5 mm pair, then uses the estimated scale and angle for a second phase-correlation pair with about 50% overlap. Each pair uses the row-start approach setting to take up slack.

Sharp uses straight boundaries; content-aware sharp routes boundaries through matching, low-detail areas. Both use one tile per pixel. Reblend keeps the saved alignment.
Stage → image mapping
These values control placement only. The raw recorded coordinates stay unchanged.
Shared calibration refinement
One stage scale and angle apply to the whole scan. Visual matches correct individual tile positions, including the first, while preserving captured pixel scale and orientation.
Feature detection sensitivity
Lower thresholds detect fainter specks. Local contrast boosts the matching image only; originals and mosaic appearance stay unchanged. Keep full resolution for tiny details. Select an overlap under Match diagnostics and try these settings before restitching.
Phase correlation settings
Correlates pixels in the stage-predicted overlap and solves all measured translations together. Uses the matching resolution and mechanical/shared correction limits above. No feature detection is required.
Low response or poor agreement after shifting rejects a pair. Response is a match score, not a probability. Originals remain unchanged.
Normalized cross-correlation settings
Finds the strongest pixel match within the stage tolerance, refines its translation to subpixel precision, then solves all tile positions together. Uses the resolution and correction limits above.
Peak-gap rejection is off at 0. Scores measure pixel agreement, not probability. Search is limited to real overlap pixels; a peak at its boundary is rejected.
Hybrid tries phase correlation, NCC, alternate illumination removal, then progressively more sensitive SIFT. Only rejected pairs are retried. Movement and match confidence limits stay unchanged; the final SIFT fallback uses full resolution.
Parallax-aware matches local patches at several resolutions, groups competing offsets, and retries against independent neighboring tiles. Confidence thresholds above apply. Try content-aware sharp seams to reduce cuts through blurred components.
